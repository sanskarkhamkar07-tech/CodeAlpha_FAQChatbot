# FAQ Buddy — CodeAlpha AI Internship Task 2

A responsive FAQ chatbot built with HTML, CSS, and JavaScript.

## Features
- FAQ dataset focused on AI and Data Science
- Text preprocessing (lowercase, punctuation cleaning, tokenization, stop-word filtering)
- Cosine similarity to match a user's question to a stored FAQ
- Chat-style user interface and suggested questions
- Fallback response when no match is confident
- Responsive desktop/mobile layout
- No API key or server required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Ask a question or click a suggested question.

## Customize the FAQ
Open `index.html` and edit the `faqs` array in the `<script>` section. Each entry has a `q` question and an `a` answer.
